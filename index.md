This revamped version of my [old whisky blog](https://duckdrams.com) is currently under construction.

Improvements
- Replace Wordpress hosting with static GitHub Pages site with Cloudflare CDN
    - cost-free, add-free
    - easy to work offline
    - entire site can be generated locally with Jekyll
- Posts saved as markdown files: easy portability
- Underlying data structures for reviews, for bottle, bottler, and distillery info: allows automatic review index, statistics etc.
